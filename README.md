# ☀️ SolarSync Pro — Universal Hybrid Inverter Management System

SolarSync Pro is an open Android telemetry & diagnostic bridge for Hybrid Solar Inverters:
- **Knox & Deye** (Solarman V5 Frame on Port 8899)
- **Inverex & Voltronic Axpert** (PI30 Serial ASCII over IP on Port 5000/23)
- **Solis Ginlong** (Modbus TCP Port 502/10000 & SolisCloud REST API)
- **Fronus, SolaX & Growatt** (Modbus SunSpec on Port 502)

### Features:
- ⚡ **Auto-Discovery Subnet Sweeper:** Automatically discovers inverters on local WiFi.
- 📊 **Real-time 2-Second Polling:** Live PV array yield, battery SoC, grid import/export & temperature.
- ⚙️ **Hardware Control:** Mode switching (Zero Export, Selling First, SBU) and charging current regulation.
- 🛠️ **Diagnostic Monitor:** Active Modbus fault code decoding.
